# meme CLI 实现计划（v0.1）

## Context

`D:\Code\meme-cli` 为空目录。依据《meme — B站梗百科 CLI 设计文档 v0.1》从零实现该工具：一个由 LLM 操作员驱动的 B站梗百科 CLI，含 7 个子命令（surf/add/edit/lookup/search/show/note）、单文件 SQLite 存储、write path 归纳（LLM）+ read path 全本地匹配检索。设计文档锁定语义与行为契约，实现细节（DDL、端点、阈值默认值）由本阶段决定。

**已完成的勘察结论**：
- **O1 已解决**：DSH 生态无裸 chat-completion 外部入口。官方适配器 wire 层说的是 Anthropic Messages 协议。归纳器采用 **DSH wire 协议直连**：`POST {DEEPSEEK_BASE_URL:-https://api.deepseek.com/anthropic}/v1/messages`，`x-api-key: $DEEPSEEK_API_KEY`，`anthropic-version: 2023-06-01`，body `{model, stream:true, messages, max_tokens, thinking:{type}, output_config:{effort}, system?, temperature?}`（已核对 `d:\deepseek-harness\packages\llm\llm-deepseek\src\serialize.ts:152-168`、`messages-api.ts`、`models.ts`）。模型 ID 直通，默认 `deepseek-flash`，目录含 `deepseek-v4-pro`。配置解析与 DSH 完全一致：`DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL`。结构化输出无原生支持 → prompt 约定 YAML 围栏 + pydantic 校验 + 一轮修复。
- DSH CLI 公民约定（将遵循）：stdout 只放机器数据；诊断走 stderr 带 `meme: ` 前缀；错误带 SCREAMING_SNAKE 稳定错误码 + 下一步建议；FTS5 用 `tokenize='unicode61'`、用户查询转义为惰性短语；SQLite 用 `application_id` 守卫 + 单调 `user_version`。
- DSH 仓库无任何 B站代码，获取器从零写。

## 技术选型

- **Python ≥3.11**，hatchling + src-layout（对齐 `d:\deepseek-harness\python\sdk` 的房子风格），入口点 `meme`
- CLI：**click 8**（help epilog 放 2-3 个可抄示例）；全局 `--json` / `--db` / `--config`
- 依赖：`click`、`httpx`（B站 + LLM SSE）、`jieba`（分词）、`pydantic≥2`（词条 schema/配置/归纳输出校验）、`numpy`、`fastembed`（本地 ONNX 向量，模型 `BAAI/bge-small-zh-v1.5` 512 维，CPU 毫秒级；懒加载，模型不可用时向量层优雅降级为纯词法）；dev：`pytest`
- **不引入**：torch 级依赖、sqlite-vec 扩展（v0.1 向量 = 库内 float32 blob + numpy 暴力余弦，千级例句毫秒级；sqlite-vec 留作升级路径）、DSH Python SDK
- SQLite：stdlib `sqlite3`（Windows 官方构建含 FTS5），`application_id=0x4D454D45`('MEME')，`user_version` 单调迁移

## 核心实现要点

**B站获取（匿名，全部失败→降级模式照常 surf）**：buvid 引导 `/x/frontend/finger/spi`；wbi 密钥 `/x/web-interface/nav`；热门 `/x/web-interface/popular`；每周必看 `/popular/series/list` + `/series/one`；分区 `/dynamic/region?rid=`（默认鬼畜 119）；目标 up `/x/space/wbi/arc/search`（匿名可能 -352/-412 → 跳过并 stderr 警告）；评论主接口 `/x/v2/reply/main?type=1&oid=&mode=2`，楼中楼 `/x/v2/reply/reply?root=`（**保留回复对**，交互梗配对样本来源）。内容寻址：`lake_videos` PK=aid、`lake_comments` PK=rpid，永不重爬。礼貌：请求间 0.8-1.5s 抖动，每轮预算默认 15 视频/视频 200 评论（可配）。

**候选证据（零 LLM）**：新评论 → jieba n-gram(1-3) 短语 + 骨架归一化双通道；增量日聚合计 `phrase_daily`/`skel_daily`（避免重扫）；候选按 head/skel 哈希 upsert，`cand_video` 链接表记跨视频/up 新颖性（每候选封顶 500 行 FIFO）；related 三级预计算（词表→`same_form`、骨架哈希→`derived`、例句向量≥0.6→`related`）。触发默认值（O2 校准标注）：`surfs_seen≥2 && 跨视频≥8 && (z≥4 || 视频≥15)`。候选状态机 pending/triggered/rejected（默认 6 轮不触发过期，O4）。

**匹配器**：五类策略照 §8.1 表。word = 别名正则 + 约束 DSL（standalone/sentence_final/forbid_context 等由归纳产出）；formula/format = 槽位 token-regex（`<num>`/`<ent>` 通配）；interaction = trigger→response 需 `--ctx` 会话上下文；derived = 父模板+变异；event = 名词短语+向量。置信分层：①② 高(0.9+)、③ 中(0.8)、④ 低(≤0.7)。miss 输出建议 `add --ctx`。

**归纳（write path 唯一 LLM 环节）**：triage 分流（word≈0 成本、event/derived 低、formula/format/interaction 旗舰）；证据包 prompt → YAML 词条（§4.3 形态）→ pydantic 校验失败喂回修复一轮；matcher 编译 → backtest（原始湖负例采样，含 LIKE 预过滤）→ 不达标自动修订一轮（命中低放宽/误报高收紧）→ 仍败则 `matcher:null` 纯向量词条；全程 audit（模型/日期/证据包引用/分数）。缺 `DEEPSEEK_API_KEY` → 响亮报错 `MEME_LLM_NO_CREDENTIAL`（read path 不受影响）。

**生命周期**：observing→active（连续≥2 轮野外命中）、active→fading（90 天窗口 -50%）、fading→tombstone（近零）、复活（归档命中→先给最小卡→确认后恢复）。遗忘=降级+压缩（fading 例句减至 1、退出默认检索权重；磁盘永不删）。edit 六动作（加变体/drift/升格/判死/修gist/复活）全记 audit 标来源。ID 永不回收。

**surf 会话（无状态 CLI）**：轮次游标存 kv_meta；`meme surf`=新一轮（获取+证据+四区第 1 页）、`--more` 翻页不重新获取、`--focus <cid>` 展开完整证据、`--round N` 呈现预算(默认 10)、`--no-fetch` 存量模式。四区：新候选(统计锚随行+related 箭头标注)/已有梗动态/衰减(只读)/欠账。

**检索与输出**：search = FTS5 BM25 + 例句级向量 + RRF(k=60)，默认 top 8；show 三级默认 card；`not found` 带 top-3 近似 + 建议动作。退出码：0=成功(含 miss，miss 是合法答案且输出形态区分)、1=工具失败、2=用法错误。`--json` 单文档 snake_case + `schema_version:1`，人机输出同源自 result 模型。排序处处稳定（分值降序、id 升序）。

**配置默认值**（`meme.example.toml` 全量注释，§12.3 四节；路径默认 `~/.meme/memes.db`，`$MEME_DB`/`--db`/配置可覆盖；`DEEPSEEK_API_KEY` 缺失只禁 add）。
